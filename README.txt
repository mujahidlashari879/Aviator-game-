SKYRUSH — Vercel starter

This is a browser-only virtual-credit crash-game prototype. It is NOT a real-money game and does not include shared multiplayer, persistent data, user accounts, deposits, or withdrawals.

DEPLOY TO VERCEL (phone-friendly option):
1. Extract the ZIP on your device or computer.
2. Create a GitHub repository and upload index.html and this README.txt.
3. In Vercel, choose Add New -> Project, import that GitHub repository, and deploy.
4. No build command is needed for this static prototype. The index.html file should be at the repository root.

Important: This prototype keeps the balance and game state in the visitor's browser only. A real shared online game requires a backend service and persistent database; Vercel static hosting alone does not make rounds synchronized between players.
